# Антон Бобков — сайт-CV

Самостоятельный статический сайт с резюме Антона Бобкова.

## Запуск

Распакуйте архив и откройте `index.html`. Сохраняйте папки `static`, `uploads` и `downloads` рядом с HTML.

Для локального сервера с Node.js выполните `npm start` и откройте http://localhost:4173. Установка зависимостей не нужна.

## Возможности

- Адаптивная вёрстка, локальный шрифт Onest и фотография.
- Светлая и тёмная темы с сохранением выбора.
- Нижняя панель: тема → PDF → копирование ссылки.
- Круглый фавикон с прозрачными углами в PNG и ICO.
- Скачивание локального PDF, копирование контактов, ссылки на проекты.
- Описания роли и результатов — 14 px, расстояние между пунктами — 6 px.
- Навыки «codex» и «github» расположены после «miro».

## Редактирование

Текст и ссылки — `index.html`, стили — `static/css/resume_public.css` и `static/gen/styles.min.css`, логика автономной версии — `static/js/offline.js`.

Основной PDF собирается из текущего `index.html` с теми же форматтерами дат и текста, кликабельными ссылками и отдельной вёрсткой A4. После изменений сайта workflow `Refresh downloadable CV` автоматически обновляет PDF, версию ссылки для кэша и запускает публикацию GitHub Pages.

Локальная пересборка PDF: установите Node.js 24 и Python 3.12, выполните `npm ci`, `python3 -m pip install -r scripts/requirements-pdf.txt` и `npm run build:pdf`. PDF рендерится локальным Chromium из зависимостей проекта. Скрипт проверяет наличие заголовков и всех ссылок перед заменой файла.

Сайт не требует сборки. `server.cjs` и `package.json` используются только для локального предпросмотра. Сохранён meta-тег `noindex, nofollow`.

Шрифт Onest распространяется по SIL Open Font License; лицензия — `static/fonts/OFL-Onest.txt`.
